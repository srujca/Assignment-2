 Project Overview

This project contains an XLSForm version of the **Criminal Risk Assessment Request** form.

The original form was converted into an XLSForm so that it can be used with platforms such as **KoboToolbox/ODK** for digital data collection.
The `survey` sheet contains the questions and structure of the form.

Important columns include:

- `type`
- `name`
- `label`
- `required`
- `relevant`
- `calculation`
- `appearance`
- `image`
I have used logo.png to get the logo in form
